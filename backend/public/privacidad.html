Tratamiento de datos personales

Politica de Privacidad

Esta politica explica como Art Huila recolecta, usa, conserva y protege los datos personales de compradores, artesanos y visitantes.

Ultima actualizacion: agosto de 2026

1. Responsable del tratamiento

Art Huila actua como responsable del tratamiento de los datos personales registrados en la plataforma. Para consultas, reclamos o solicitudes relacionadas con datos personales, el titular puede escribir al correo de contacto oficial indicado por la plataforma.

2. Datos que podemos recolectar

Podemos recolectar nombre, correo electronico, telefono, direccion de envio, ciudad, departamento, historial de pedidos, datos de pago procesados por terceros autorizados, informacion de perfil de artesano, imagenes de productos, documentos de soporte cargados por artesanos y datos tecnicos basicos de uso del sitio.

3. Finalidades

Usamos los datos para crear y administrar cuentas, procesar compras, coordinar envios, validar perfiles de artesanos, publicar productos, enviar notificaciones transaccionales, responder solicitudes de soporte, prevenir fraude, cumplir obligaciones legales y mejorar la experiencia del servicio.

4. Autorizacion

Al registrarse, comprar, postularse como artesano o usar los formularios de la plataforma, el usuario autoriza el tratamiento de sus datos personales para las finalidades informadas. Los datos sensibles o documentos de identidad se solicitan solo para procesos de validacion y seguridad de la plataforma.

5. Encargados y terceros

La plataforma puede usar proveedores tecnologicos para almacenamiento, base de datos, correo, pagos, imagenes y logistica. Estos terceros solo deben tratar los datos necesarios para prestar el servicio correspondiente.

6. Derechos del titular

El titular puede conocer, actualizar, rectificar, solicitar prueba de autorizacion, solicitar supresion cuando proceda, revocar autorizaciones y presentar consultas o reclamos conforme a la normativa colombiana de proteccion de datos personales.

7. Seguridad

Art Huila adopta medidas tecnicas, administrativas y operativas razonables para proteger la informacion contra perdida, acceso no autorizado, alteracion o uso indebido. Ningun sistema es completamente infalible, por lo que tambien se recomienda a los usuarios proteger sus credenciales.

8. Conservacion

Los datos se conservaran durante el tiempo necesario para cumplir las finalidades del servicio, obligaciones legales, contables, contractuales y de seguridad. Cuando ya no sean necesarios, podran eliminarse o anonimizarse.

9. Menores de edad

La plataforma no esta dirigida a menores de edad. Si se identifica informacion de un menor sin autorizacion valida, se podra solicitar su eliminacion.

10. Cambios

Esta politica puede actualizarse. Las modificaciones importantes seran publicadas en esta pagina.

Nota: este documento es una base informativa para el proyecto academico/comercial y debe ser revisado por asesoria juridica antes de una operacion real a gran escala.
